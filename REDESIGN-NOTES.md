# Apple Worm Adventure — Visual Redesign

This redesign preserves the existing React/Vite and backend functionality while refreshing the UI styling.

## Visual updates
- Premium dark forest palette with layered gradients, softer borders, depth and glass-like header.
- Improved dashboard cards, level tiles, controls, rewards, modals, and responsive spacing.
- Gameplay board is larger (up to 680px), with enhanced cell styling and a more dimensional surface.
- Replaced the small worm emoji with CSS-drawn worm head/body visuals (large, glossy green segments, eyes and smile).
- Added subtle glow/pulse treatment for hints and gold apples.

## Run locally
1. Open the `client` folder in terminal.
2. Run `npm install`.
3. Run `npm run dev`.

No backend/API logic was intentionally changed.
